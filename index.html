📖 Lore du serveur

Bienvenue sur le Communism SMP.

Deux forces s’affrontent :

  • Les Communistes qui construisent et aident le peuple
  • Les Résistants qui sabotent et créent le chaos
La guerre entre les deux factions façonne le monde.Il faut une raison pour faire une guerre

☭ Communistes

Les communistes gèrent la société du serveur.

  • Remplissent les coffres publics
  • Aident les constructions de la Place du Peuple
  • Font des quêtes pour des récompenses
  • Il peuvent postuler pour plusieurs métiérs(Builder,Commercant,Police,etc...)

⚠️ Mauvais comportement = punition immédiate → transfert en Résistant.

🕵️ Résistants

Les résistants sont divisés en plusieurs types :

  • Taupes : anciens communistes infiltrés
  • Résistants actifs : rejoignent des clans
  • Résistants discrets : sabotent sans se faire repérer

Objectif : perturber le système communiste et créer le chaos.

👑 DCM

Les DCM (Dirigeants Communistes Minecraft) dirigent le système communiste.

  • Gèrent les décisions importantes
  • Attribuent les rôles
  • Organisent les projets publics

📜 Rules

  • No hacking / cheating
  • Respect RP roles
  • No spawn grief
  • Follow your faction rules

Le non-respect entraîne une sanction immédiate ou un changement de faction.
